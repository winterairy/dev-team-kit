# 배포 점검표: Electron (electron-builder)

- **빌드 대상**: 대상 OS·형식(NSIS, dmg, AppImage 등)과 아키텍처. 이 환경에서 만들 수 없는 대상은 "사용자 확인 필요"
- **포함 파일**: `files` 설정이 빌드 산출물만 포함하는지. 소스맵, 테스트 데이터, `.env`가 들어가지 않는지
- **코드 서명**: 인증서 준비 상태와 저장 위치(CI 시크릿). 서명 없는 설치 파일의 경고를 문서화
- **자동 업데이트**: 쓰는지, 쓴다면 게시 위치와 채널
- **CI**: OS별 러너(예: Windows 설치 파일은 `windows-latest`)에서 빌드하는 워크플로. 산출물 업로드
- **설치·제거 확인 절차**: 사용자가 실제 OS에서 설치 → 실행 → 업데이트 → 제거를 확인하는 단계를 운영 문서에 적는다
- 실행하지 않을 명령 예: 릴리스 게시, 태그 push
