# 보안 점검표: Node CLI·라이브러리

- **명령 실행**: `child_process`에 사용자 입력이 셸 문자열로 들어가는지 (`exec` 대신 `execFile`·인자 배열 사용 여부)
- **경로 처리**: 사용자가 준 경로로 쓰기·삭제할 때 대상 폴더 밖으로 나가지 않는지
- **설치 스크립트**: `postinstall` 등 설치 시 실행되는 스크립트가 하는 일
- **게시 범위**: 패키지에 포함되는 파일(`files`, `.npmignore`)에 비밀값·테스트 데이터가 섞이지 않는지
- **역직렬화**: 외부 JSON·YAML을 검증 없이 객체로 쓰는지 (프로토타입 오염)
